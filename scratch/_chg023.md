### 1. Business（业务影响）

**本 Feature 补齐了闭环里的「练完即创」一段**：

| 项 | 含义 |
| :--- | :--- |
| **进得去** | 每个工具有了**独立的路由级详情页**（可深链、可刷新），三种集成模式各有正确行为 |
| **出得来** | 生成成功 ⇒ 资产**自动就绪**；**失败 / 超时 ⇒ 积分全额原路退还**（"不为失败的渲染付钱"成为可验收承诺） |
| **送得到** | 成片可**直接提交为商单交付物**或**分享至社区**，且**附件复用同一对象键、不重复占用存储** |
| **口径校正** | 扣分从「渲染成功后才扣、硬编码 `self`、余额不足静默放行」校正为「**生成前预扣、按来源分池、不足即拒绝**」 |
